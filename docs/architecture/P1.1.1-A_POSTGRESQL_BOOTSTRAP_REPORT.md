### 3. Cryptographic Ledger & Audit Event Ownership

`audit_events` has been enhanced with:
- `merchant_id TEXT NULL` column.
- Index `idx_audit_events_merchant ON audit_events (merchant_id)`.
- Portable backfill query:
  ```sql
  UPDATE audit_events
  SET merchant_id = (
      SELECT r.merchant_id 
      FROM audit_records r 
      WHERE r.transaction_id = audit_events.transaction_id
      LIMIT 1
  )
  WHERE merchant_id IS NULL
    AND EXISTS (
      SELECT 1 FROM audit_records r
      WHERE r.transaction_id = audit_events.transaction_id
        AND r.merchant_id IS NOT NULL
  );
  ```
- **Cryptographic Invariant Preserved**: `compute_event_hash` continues to compute SHA-256 over `payload_json`, `timestamp`, `event_type`, `transaction_id`, and `prev_hash`. Adding `merchant_id` to the column layout does not perturb the hash chain.
- Live test execution confirms:
  `store.verify_integrity()` -> `{'valid': True, 'status': 'VERIFIED_IMMUTABLE'}`.

### 4. RLS Migration Preparation (`001_postgresql_rls_hardening.sql`)

The migration file has been updated with:
1. `audit_events` Row-Level Security:
   ```sql
   ALTER TABLE audit_events ENABLE ROW LEVEL SECURITY;
   ALTER TABLE audit_events FORCE ROW LEVEL SECURITY;

   DROP POLICY IF EXISTS tenant_isolation_audit_events ON audit_events;
   CREATE POLICY tenant_isolation_audit_events ON audit_events
       AS RESTRICTIVE
       FOR ALL
       USING (
           merchant_id = NULLIF(current_setting('app.current_merchant_id', true), '')
           AND merchant_id IS NOT NULL
       )
       WITH CHECK (
           merchant_id = NULLIF(current_setting('app.current_merchant_id', true), '')
           AND merchant_id IS NOT NULL
       );
   ```
   *Security Note:* `merchant_id IS NOT NULL` prevents merchant employees from ever reading or forging system-level audit events.
2. Removal of `ALTER ROLE gateway_admin BYPASSRLS;`. Replaced with explicit `ALTER ROLE gateway_admin NOBYPASSRLS;` and `ALTER ROLE app_user NOBYPASSRLS;`.
3. Compound indexes for high-throughput tenant filtering (`idx_audit_events_tenant`, `idx_cat_prod_tenant`, `idx_audit_records_tenant`).
